> вторая задача:
> Дан массив целых чисел nums и целое число target.
> Нужно найти индексы двух различных элементов массива, сумма которых равна target.
>
> Гарантируется, что решение существует в единственном экземпляре, и один и тот же элемент нельзя использовать дважды.
>
> Пример
> nums = [2, 7, 11, 15], target = 9 → [0, 1]
> nums = [3, 2, 4], target = 6 → [1, 2]
>
> решение:
>
> def two_sum(nums, target):
>     seen = {}
>     for idx, num in enumerate(nums):
>         complement = target - num
>         if complement in seen:
>             return [seen[complement], idx]
>         seen[num] = idx
>     return []  # если пар

> третья:
> Дана таблица prices, содержащая информацию о товарах:
>
> product_id — идентификатор товара
> product_name — название товара

> Нужно для каждой категории вывести товар с максимальной ценой.
>
> решение:
>
>  SELECT product_id, product_name, category, price
> FROM (
>     SELECT *,
>            ROW_NUMBER() OVER (PARTITION BY category ORDER BY price DESC) as rn

>
> Решение:
>
> SELECT DISTINCT employee_id
> FROM (
>     SELECT employee_id, city, COUNT(DISTINCT customer_id) AS unique_customers
>     FROM orders
>     WHERE EXTRACT(YEAR FROM order_date) = 2022
>     GROUP BY employee_id, city
> ) sub
> WHERE unique_customers > 1;
