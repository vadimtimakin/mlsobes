# ML Clan — навигатор вопросов

Фильтры применяются **к интервью**, а исключения LLM/NLP/CV/RecSys — **к отдельным вопросам**. Поэтому смешанное интервью не исчезает целиком. По умолчанию вопросы ранжируются так: число разных компаний → число разных интервью → свежесть.

> [!note]
> Смысловые дубли здесь не склеиваются автоматически. Полностью одинаковые формулировки сводятся механически, а смысловые объединения делает Codex после проверки контекста.

```dataviewjs
await dv.view(`${dv.current().file.folder}/view`, {});
```
